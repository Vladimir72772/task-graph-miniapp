# Граф задач: мини-приложение Telegram

Страница для быстрого ввода с телефона: занятия, траты, напоминания и задачи.

- Записи складываются в отдельный **закрытый** репозиторий (по файлу на запись в папке `inbox/`).
- Программа «Граф задач» на компьютере раз в минуту забирает их, применяет и удаляет из репозитория.
- Обратно в закрытый репозиторий кладётся только `state.json`: категории, текущее занятие, теги, названия проектов и вопросы о расхождениях.

В этом репозитории нет данных и ключей. Репозиторий и токен вводятся в настройках самой страницы
и хранятся в облаке Telegram и на телефоне.

Если записи нельзя отправить (нет сети или не подключён репозиторий), они ждут в очереди на телефоне,
а страница предлагает отправить ту же запись текстом в чат с ботом.
